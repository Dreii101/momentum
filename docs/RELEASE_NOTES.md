# Momentum 1.0.0 preview — build 2

First public source snapshot and GitHub preview packages. Includes offline tasks/Today, plain-text linked notes, courses/classes, unified calendar/manual planning, persistent starter/focus/review, confirmed-work progress/reflection, opt-in local reminders and validated JSON replacement backup.

This is not a Microsoft Store or Google Play release. Installed-release acceptance, signed update preservation, physical notification/recovery behavior and post-reinstall restoration remain pending. Android development previews using a different key need a backup-first transition. The private Windows MSIX requires a separate explicit certificate-trust decision. Keep a validated backup outside app storage and retain private signing keys. No Version 2 features, cloud synchronization, app accounts or analytics were added.
